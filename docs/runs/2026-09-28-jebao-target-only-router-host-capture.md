## 이번에 새로 확정한 것과 한계

두 관측점에서 포트 조건 없이 세 binding의 패킷만 실제 파일로 기록할 수 있고, 위 고정 사본에는 대상 밖 패킷이 없다. 실행 중 파일의 마지막 레코드는 읽는 순간 미완성일 수 있어 고정 사본을 따로 재해독·해시 검증했다. 공유기 수집 서비스의 자동 재시작 카운터 `NRestarts=0`, 현재 배포 스크립트의 구문 검사 및 배포본 해시 일치도 확인했다. 새 binding 출처를 시험하려고 5GHz AP 서비스는 수동으로 한 번 재시작했다.

이것은 **관측한 인터페이스에서 BPF에 맞는 프레임을 기록했다**는 뜻이지 모든 무선 프레임의 무손실 포착을 증명하지 않는다. 드라이버가 내놓지 않는 802.11 원본, Bluetooth, 앱→cloud 상행, 장비 내부 신호는 여전히 범위 밖이다. 현재 고정 사본만으로 Master→Slave 전달 매체나 실제 위상도 결정할 수 없다. IP가 바뀌면 실행 중 필터는 재계산되지 않으며, 새 기동 시 private binding을 다시 확인해야 한다.
