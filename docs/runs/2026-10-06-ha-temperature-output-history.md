# HA 수온 그래프의 가열·냉각 구간 표시

## 질문과 결과

HA에 저장된 실제 출력 상태 이력을 수온 그래프의 같은 24시간 축에 표시할 수 있는지
확인했다. 출력 센서 이력 조회와 실제 HA 표시를 확인했으며, 수온과 목표값의 차이로
가열·냉각 상태를 추정하지 않는다. 현재 조회된 출력 이력은 `idle`뿐이었다.
물리 장비를 가열·냉각으로 전환하는 시험은 하지 않았으므로 실제 전환 구간의 실측
검증까지 완료했다고 주장하지 않는다.

기준 HEAD는 `bf2f5d72e40d6a7424c85e001dd9c45eae41ad56`이다. 기존 작업트리의
overview 카드와 테스트를 수정하고 표시 전용 브라우저 테스트를 추가했다.
동결 하네스, `src/`, 장비 설정과 운전 일정은 변경하지 않았다.

## 구현과 검증

- 설정된 출력 센서를 우선 사용하고, 출력 센서 설정이 없는 경우에만 climate의
  `hvac_action`을 사용한다. 브라우저는 HA 저장 이력을 읽으며 장비에 조회·제어
  명령을 추가하지 않는다.
- 가열은 주황색, 냉각은 파란색 배경 구간으로 표시한다. 대기는 기존 배경을 유지하고,
  꺼짐은 회색, 기록 없음·미확인은 빗금으로 구분한다. 범례, 구간별 시간 안내와
  기록된 가열·냉각 누적 분을 함께 표시한다.
- 24시간 경계 직전 상태는 왼쪽 경계에 유지한다. 조회 완료 시각 이후는 미확인으로
  남기며, 조회 실패를 대기로 해석하거나 이전 가열·냉각 상태를 미래로 연장하지 않는다.
- 화면이 열린 동안 출력 이력을 1분 간격으로 갱신한다. 실제 화면의 조회 종료 시각은
  `2026-10-06T08:16:46.746Z`에서 `2026-10-06T08:18:46.750Z`로 자동 갱신됐다.
  `2026-10-06T08:19:28.815Z` 확인 시 오류 없이 가열 0분·냉각 0분을 표시했다.
- overview 테스트는 구간 분할, 시간 경계, 누락·꺼짐, 조회 실패와 설정 변경 중
  이전 요청 응답의 혼입 방지를 검사했다. 기존 24시간 시작점 회귀 검사도 통과했다.
- return·utility·GMP schedule·bar schedule 카드 테스트, JS 구문 검사와
  `git diff --check`를 통과했다. 구현 에이전트가 변경 코드를 재독했다.
- 별도 로컬 브라우저 테스트는 가상 이력임을 명시하고 가열·냉각·미확인 색 구간,
  시간 안내, 1440px·390px 화면의 범례 및 가로 넘침을 검사했다. 실제 HA나 장비와
  연결하지 않은 표시 계약 테스트이며, 장비 동작의 근거로 사용하지 않는다.
